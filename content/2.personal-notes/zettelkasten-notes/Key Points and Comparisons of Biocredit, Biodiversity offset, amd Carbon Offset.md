# 生物信用額度、生物多樣性抵換、碳抵換的重點與比較

- 目前關於是否能生物信用額度用於抵換與補償，可能還沒有明確共識，因此可分為[[衡量生物信用額度生物多樣性成果的途徑-2.生物信用額度的定義與類別#抵換使用情境：減緩層級中的定位|非抵換或非補償的生物信用額度]]和[[衡量生物信用額度生物多樣性成果的途徑-2.生物信用額度的定義與類別#抵換使用情境：IAPB 的在地同類補償|支持可用於抵換或補償的生物信用額度]]。以下將前者稱為生物信用額度，後者稱為生物多樣性抵換

|           | 生物信用額度                                   | 生物多樣性抵換                                                   | 碳抵換                     |
| --------- | ---------------------------------------- | --------------------------------------------------------- | ----------------------- |
| 目的        | • 不一定與補償特定損害有關<br>• 旨在為增強或保護生物多樣性淨效益提供資金 | • 透過在其他地方，對生物多樣性創造相等的正面影響來彌補負面的環境影響<br>• 旨在達成生物多樣性的「零淨損失」 | • 讓排放源透過購買減量額度，抵銷等量的排放量 |
| 能否用於抵換或補償 | • 非補償性，資金用於保育與復育                         | • 用於補償開發等造成的負面影響<br>• 可能只被接受用於在地、同類型生態系的補償，國際抵換難以實施       | • 可以抵銷排放                |
| 地點限制      | • 不同地點的信用額度將難以等值比較                       | • 嚴格限制需同地點、同類型生態系                                         | • 不受地點限制                |
| 衡量單位      | • 需以多個指標度量彙整成綜合指標                        | • 需判定損失與補償之間的生態等價性，實施困難                                   | • 噸二氧化碳當量，單一且可相加        |
