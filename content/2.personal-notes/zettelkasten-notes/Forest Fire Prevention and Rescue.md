# 災害預防

- 林地經營管理措施
- 嚴格執行引火許可規定
- 教育訓練與知識宣導
- 加強森林火災相關研究

# 災前整備

- 建立應變機制
- 災情蒐集、通報與分析應用整備
- 滅火應變作業整備
- 緊急醫療救護整備
- 緊急運送整備
- 疏散撤離整備
- 避難收容整備
- 物資供應調度整備
- 提供災名災情資訊整備
- 二次災害防止整備
- 災害防救之訓練、演習
- 災後復原重建整備

# 緊急應變

- 災前應變
  - 發布警戒資訊
  - 避難引導與警戒管制
- 災情蒐集、通報與通訊確保
- 緊急應變機制
  - 開設災害應變中心
  - 啟動緊急動員機制
- 相互支援機制
- 搜救及緊急醫療救護
- 緊急運送
- 疏散撤離與避難收容
- 食物、飲用水及生活必需品之調度、供應
- 設施、設備之緊急修復
- 提供受災民眾災情資訊
- 支援協助之受理
- 二次災害防止

# 復原重建

- 災害調查
- 緊急復原
- 災明生活重建支援
- 計畫性復原重建
