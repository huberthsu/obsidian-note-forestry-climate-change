# 台灣自然保護區域介紹

## [自然保留區](https://www.forest.gov.tw/reserve)

- 法源依據: [文化資產保存法](https://law.moj.gov.tw/LawClass/LawAll.aspx?PCode=H0170001)
- 文化資產保存法第4條: 主管機關
  - 在中央為文化部；在直轄市為直轄市政府；在縣（市）為縣（市）政府。
  - 陸域（含淡水水域）之自然地景及自然紀念物中央主管機關為農業部
  - 海域之自然地景及自然紀念物中央主管機關為海洋委員會
- 文化資產保存法第86條規定：「自然保留區禁止改變或破壞其原有自然狀態」，故自然保留區已受到政府單位最嚴格的保護，以保存其原有自然狀態，並提供學術研究及教育宣導方面的功能與價值
  - 違反規定，改變或破壞自然保留區之自然狀態者，處六個月以上五年以下有期徒刑，得併科新臺幣500,000元以上20,000,000元以下罰金
- 若欲進入自然保留區，須透過[自然保護區域進入申請系統](https://pa.forest.gov.tw/index.php) 申請
  - 未經主管機關許可任意進入自然保留區者，處新臺幣30,000元以上150,000元以下罰鍰
- [圖資](https://data.moa.gov.tw/open_detail.aspx?id=157)

## [野生動物保護區](https://www.forest.gov.tw/protectarea)

- 法源依據: [野生動物保育法](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=M0120001)
- 野生動物保育法第2條: 主管機關
  - 本法所稱主管機關：在中央為農業部；在直轄市為直轄市政府；在縣（市）為縣（市）政府。但海域野生動物保育之中央主管機關為海洋委員會。
- 野生動物保育法第10條: 設立
  - 地方主管機關得就野生動物重要棲息環境有特別保護必要者，劃定為野生動物保護區，擬訂保育計畫並執行
- 野生動物保育法第10條: 保育計畫公告管制事項
  - 騷擾、虐待、獵捕或宰殺一般類野生動物等行為
  - 採集、砍伐植物等行為
  - 污染、破壞環境等行為
  - 其他禁止或許可行為
- 野生動物保育法第41條: 罰則
  - 有下列情形之一，處六月以上五年以下有期徒刑，得併科新臺幣200,000元以上1,000,000元以下罰金
    - 未具第18條第一項第一款之條件，獵捕、宰殺保育類野生動物者
    - 違反第18條第一項第二款規定，未經中央主管機關許可，獵捕、宰殺保育類野生動物者
    - 違反第19條第一項規定，使用禁止之方式，獵捕、宰殺保育類野生動物者
    - 於劃定之野生動物保護區內，犯前項之罪者，加重其刑至三分之一
- 野生動物保育法第42條: 罰則
  - 有下列情形之一，處一年以下有期徒刑、拘役或科或併科新臺幣60,000元以上300,000元以下罰金；其因而致野生動物死亡者，處二年以下有期徒刑、拘役或科或併科新臺幣100,000元以上500,000元以下罰金：
    - 未具第18條第一項第一款之條件，騷擾、虐待保育類野生動物者
    - 違反第18條第一項第二款規定，未經中央主管機關許可，騷擾、虐待保育類野生動物者
    - 於劃定之野生動物保護區內，犯前項之罪者，加重其刑至三分之一
- [圖資](https://data.moa.gov.tw/open_detail.aspx?id=162)

## [野生動物重要棲息環境](https://www.forest.gov.tw/wildlife_habitats)

- 法源依據: [野生動物保育法](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=M0120001)
- 野生動物保育法第2條: 主管機關
  - 本法所稱主管機關：在中央為農業部；在直轄市為直轄市政府；在縣（市）為縣（市）政府。但海域野生動物保育之中央主管機關為海洋委員會。
- 野生動物保育法第8條: 野生動物重要棲息環境之類別及範圍，由中央主管機關公告之；變更時，亦同。
- [圖資](https://data.moa.gov.tw/open_detail.aspx?id=156)

## 國家公園

- 法源依據: [國家公園法](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=D0070105)
- 國家公園法第3條: 主管機關
  - 國家公園主管機關為內政部
- 國家公園法第6條: 國家公園之選定基準
  - 具有特殊景觀，或重要生態系統、生物多樣性棲地，足以代表國家自然遺產者
  - 具有重要之文化資產及史蹟，其自然及人文環境富有文化教育意義，足以培育國民情操，需由國家長期保存者
  - 具有天然育樂資源，風貌特異，足以陶冶國民情性，供遊憩觀賞者
- 國家公園法第12條: 分區
  - 一般管制區
  - 遊憩區
  - 史蹟保存區
  - 特別景觀區
  - 生態保護區
- 國家公園法第13條: 禁止行為
  - 國家公園區域內禁止左列行為：
    - 焚燬草木或引火整地
    - 狩獵動物或捕捉魚類
    - 污染水質或空氣
    - 採折花木
    - 於樹木、岩石及標示牌加刻文字或圖形
    - 任意拋棄果皮、紙屑或其他污物
    - 將車輛開進規定以外之地區
    - 其他經國家公園主管機關禁止之行為
- 國家公園法第18條: 生態保護區相關規定
  - 生態保護區應優先於公有土地內設置，其區域內禁止採集標本、使用農藥及興建一切人工設施。但為供學術研究或為供公共安全及公園管理上特殊需要，經內政部許可者，不在此限
- 國家公園法第19條: 進入生態保護區
  - 進入生態保護區者，應經國家公園管理處之許可

## 國家自然公園

- 法源依據: [國家公園法](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=D0070105)
- 國家公園法第3條: 主管機關
  - 國家公園主管機關為內政部
- 國家公園法第6條: 設立
  - 合於國家公園選定基準而其資源豐度或面積規模較小，得經主管機關選定為國家自然公園

## [自然保護區](https://www.forest.gov.tw/nature_protect)

- 法源依據: [森林法](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=M0040001)
- 森林法第2條: 主管機關
  - 在中央為行政院農業委員會；在直轄市為直轄市政府；在縣（市）為縣（市）政府
- 森林法第17條: 設立
  - 為維護森林生態環境，保存生物多樣性，森林區域內，得設置自然保護區，並依其資源特性，管制人員及交通工具入出；其設置與廢止條件、管理經營方式及許可、管制事項之辦法，由中央主管機關定之。
- 森林法第56-2條: 罰則
  - 在森林遊樂區、自然保護區內，未經主管機關許可，有左列行為之一者，處新臺幣50,000元以上200,000元以下罰鍰
    - 設置廣告、招牌或其他類似物
    - 採集標本
    - 焚毀草木
    - 填塞、改道或擴展水道或水面
    - 經營客、貨運
    - 使用交通工具影響森林環境
- 森林法第56-3條: 罰則
  - 有左列情形之一者，處新臺幣1,000元以上60,000元以下罰鍰
    - 未依第39條第一項規定辦理登記，經通知仍不辦理者
    - 在森林遊樂區或自然保護區內，有下列行為之一者
      - 採折花木，或於樹木、岩石、標示、解說牌或其他土地定著物加刻文字或圖形
      - 經營流動攤販
      - 隨地吐痰、拋棄瓜果、紙屑或其他廢棄物
      - 污染地面、牆壁、樑柱、水體、空氣或製造噪音
    - 在自然保護區內騷擾或毀損野生動物巢穴
    - 擅自進入自然保護區內
  - 原住民族基於生活慣俗需要之行為，不受前條及前項各款規定之限制
- [圖資](https://data.moa.gov.tw/open_detail.aspx?id=350)

# 比較表

| 保護區類別          | 法源依據    | 中央主管機關                        | 設立條件/目的                       |
| -------------- | ------- | ----------------------------- | ----------------------------- |
| **自然保留區**      | 文化資產保存法 | 文化部；農業部（陸域自然地景/紀念物）；海洋委員會（海域） | 保存自然狀態、提供學術研究及教育宣導            |
| **自然保護區**      | 森林法     | 農業部                           | 維護森林生態、保存生物多樣性，於森林區域內設置       |
| **野生動物保護區**    | 野生動物保育法 | 農業部                           | 野生動物重要棲息環境且有特別保護必要            |
| **野生動物重要棲息環境** | 野生動物保育法 | 農業部                           | 由中央公告的野生動物棲息地類別與範圍            |
| **國家公園**       | 國家公園法   | 內政部                           | 具特殊景觀、重要生態系/生物多樣性、文化資產、天然育樂資源 |
| **國家自然公園**     | 國家公園法   | 內政部                           | 合於國家公園基準但資源豐度或面積較小            |
