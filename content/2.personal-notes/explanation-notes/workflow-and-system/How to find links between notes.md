## 說明

- breadcrumns
  - 藉由筆記的parent、child、sibling，持續探索潛在關聯筆記
- 關聯圖
  - 利用[[Neighbourhood Graph plugins]]與[[inline local graph plugins]]功能，從關聯圖的連結與**shared tags**中找尋潛在相關筆記
- 反向連結-未連結但題級本筆記的檔案
  - 可結合別名欄位應用，參考[[The aliases function can be used with files that are not linked to but mention this note.]]
- bases
  - 於bases中用過濾功能選擇相關tags、檔案標籤
- claudian
  - 若為文獻筆記，可由ai補充中的建議相關筆記與建議建立筆記，甚至是相關問題
