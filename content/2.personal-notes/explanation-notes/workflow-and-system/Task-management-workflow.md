# 說明

記錄[[Task Management]]這則任務管理筆記目前的架構與設計

# 整體架構：Plan → Do → Check

## 一、規劃任務（Plan）

週目標表格，欄位：

- 工作量(大/中/小)
  - 用來判斷每週安排的工作量會不會偏重，不算在任務紀錄統計內。
- 可用天數
  - 0(整天不可用)、0.5(部分佔用)、1(正常)，將每周可用天數加總後填在可用天數欄位內
    - 最多6天，1天休息或彈性使用
    - 事件可記錄於[[重要日期]]，並說明將部分占用或使整天不可用
- 完成考古題參考答案
  1. 拆解、分析題目
  2. 蒐集參考答案所需的相關文獻或資料
  3. 建立文獻筆記與卡片盒筆記
  4. 完成參考答案
- 卡片盒筆記回顧次數
  - 卡片盒筆記的產出數量無法直接控制，改成用「回顧文獻/靈感筆記的次數」當目標

## 二、追蹤任務（Do）

分兩條線，因為節奏不同：

- **主任務**：英文學習筆記、英文測驗練習、完成考古題參考答案、考古題複習、卡片盒筆記回顧
  - 用 [[fancy kanban plugins|fancy kanban]]的code block 直接將未開始/進行中/已完成的kanban嵌在筆記裡
  - 可拖曳。每天開始前要手動把卡片撥回「未開始」，沒有自動重置機制。
- **其他雜事**：
  - 連結到[[其他雜事kanban]]

## 三、任務紀錄（Check 的資料來源）

五個主任務分兩種資料來源，統計時對應不同算法：

- **手動維護（3項）**：完成考古題參考答案、卡片盒筆記回顧、英文測驗練習
  - 存在 [[Task Management]] 自己的 frontmatter 屬性（`本月完成考古題參考答案`、`本月卡片盒筆記回顧`、`本月英文測驗練習`），做完就手動 +1
  - 沒有留逐次日期紀錄，只有本月累計數字；每月初手動抄一行到「歷史統計」封存表後歸零
- **自動統計（2項）**：英文學習筆記、考古題練習
  - 英文學習筆記：算 `2.personal-notes` 底下 category 含 `English learning notes` 且 `date` 落在本月的筆記數量
  - 考古題練習：每份考古題筆記自己的 `已練習次數` 屬性會逐次累加（`date` 只覆寫成最近一次作答日），本月次數 = 所有考古題筆記 `已練習次數` 加總 − `本月考古題練習_月初基準`；月初把當時算出的本月次數一併抄進「歷史統計」封存表，再按筆記裡的「月初重置」按鈕把基準更新成當下加總值

以[[monthly tasks calendar bases.base]] 補充筆記層級明細，裡面有3個 view：

1. **本月任務紀錄**(月曆): 依各筆記的 `date` 屬性畫在月曆上，內建上一頁/下一頁可翻到任何月份
2. **本月統計**(表格-依類型分組): 統計這個月「英文學習筆記/考古題筆記/卡片盒筆記」各類型筆記分別完成幾篇（筆記層級明細，跟上面自動統計 2 項算法一致但含卡片盒筆記類別）
3. **歷史統計**(表格-依月分分組): 查看各月份總共完成的筆記數量
