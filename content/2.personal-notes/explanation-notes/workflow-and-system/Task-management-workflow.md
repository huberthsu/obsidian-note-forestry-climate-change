# 說明

記錄[[Task Management]]這則任務管理筆記目前的架構與設計

# 整體架構：Plan → Do → Check

## 一、規劃任務（Plan）

週目標表格，欄位：

- 工作量(大/中/小)
  - 用來判斷每週安排的工作量會不會偏重，不算在任務紀錄統計內。
- 可用天數
  - 0(整天不可用)、0.5(部分佔用)、1(正常)，將每周可用天數加總後填在可用天數欄位內
    - 最多6天，1天休息或彈性使用
    - 事件可記錄於[[重要日期]]，並說明將部分占用或使整天不可用
- 完成考古題參考答案
  1. 拆解、分析題目
  2. 蒐集參考答案所需的相關文獻或資料
  3. 建立文獻筆記與卡片盒筆記
  4. 完成參考答案
- 卡片盒筆記回顧次數
  - 卡片盒筆記的產出數量無法直接控制，改成用「回顧文獻/靈感筆記的次數」當目標

## 二、追蹤任務（Do）

分兩條線，因為節奏不同：

- **主任務**：英文學習筆記、英文測驗練習、完成考古題參考答案、考古題複習、卡片盒筆記回顧
  - 用 [[fancy kanban plugins|fancy kanban]]的code block 直接將未開始/進行中/已完成的kanban嵌在筆記裡
  - 可拖曳。每天開始前要手動把卡片撥回「未開始」，沒有自動重置機制。
- **其他雜事**：
  - 連結到[[其他雜事kanban]]

## 三、任務紀錄（Check 的資料來源）

嵌入 [[monthly tasks calendar bases.base]]，裡面有三個 view：

1. **本月任務紀錄**(月曆): 依各筆記的 `date` 屬性畫在月曆上，內建上一頁/下一頁可翻到任何月份
2. **本月統計**(表格-依類型分組): 統計這個月各類型筆記分別完成幾篇
3. **歷史統計**(表格-依月分分組): 查看各月份總共完成的筆記數量
