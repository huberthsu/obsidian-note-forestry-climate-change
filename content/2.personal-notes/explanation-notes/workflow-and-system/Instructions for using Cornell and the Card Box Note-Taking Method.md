# 說明

- [康乃爾筆記法](https://www.youtube.com/watch?v=9SHrgilRKtU)
  - 將筆記分為筆記欄、整理欄、摘要欄
    - 筆記欄: 可詳細**記錄演講、課堂、文獻內容**
    - 整理欄: 可摘錄關鍵字重點、依據筆記欄內容列問題或考古題
    - 摘要欄: 可整理重點、紀錄知識之間關連性、舉例、感想、補充資料
  - [[Literature notes template|文獻筆記模板]]模板中應用了此方法
- 卡片盒筆記法
  - 概念
    - 一張卡片只記錄一個重點
    - 利用雙向連結，建立卡片之間關連性
  - 筆記類型
    - 靈感筆記
    - 文獻筆記
    - 永久筆記
  - 撰寫5步驟
    - 寫下靈感
    - 卡片分類
    - 建立內容大綱
    - 組織排列卡片
    - 修改和編輯文章
  - [[Inspiration notes template|靈感紀錄模板]]模板應用了此方法
  - 相關影片連結
    - [卡片盒筆記法重點](https://www.youtube.com/watch?v=O5_QvQ7A-Kk)
    - [應用卡片盒筆記法撰寫文章](https://www.youtube.com/watch?v=YW3Az-Oi674\&t=5s)
