# 核心功能與用途

- 可以使用gui介面創建與編輯心智圖，再用!\[\[]]功能插入到筆記內
- 可以用心智圖檢視該筆記架構
- 重點為該筆記架構與自由編輯，而非[[Breadcrumbs plugins]]顯示不同筆記間的層級架構

# 使用說明

- ctrl+p-預覽為心智圖
  - 可以用心智圖檢視該篇筆記架構
- ctrl+p-新建思維導圖/ctrl+p-新建思維導圖並插入當前文件
  - 可以創建一個獨立檔案，自由繪製心智圖。==繪製完後要按保存並更新預覽影像，才會正確顯示於筆記內==
  - 能以!\[\[]]功能插入筆記內
  - 已設定自動儲存於畫布與心智圖資料夾-心智圖內
