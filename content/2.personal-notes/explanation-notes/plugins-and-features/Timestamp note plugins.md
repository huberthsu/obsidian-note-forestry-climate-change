# 核心功能與用途

- 將連結插入的影片放到右側邊欄中播放
- 可建立timestamp直接跳轉到影片對應片段
- **可將其用於協助做影片筆記**

# 使用說明

- 插入影片到側邊欄
  - 反白網址
  - ctrl+p選open video player
- 建立timestamp
  - 語法參考

```timestamp
4:50
```
