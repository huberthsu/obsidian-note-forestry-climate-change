# 什麼是ai agent

- 以大語言模型為大腦，具備感知能力，能採取相對應的行為，並達成使用者目標或完成多步驟任務的人工智慧

# ai agent的核心能力

- 感知能力
  - 能理解輸入資訊(文字、語境、上下文、環境)，並可提取關鍵訊息與特徵
  - 可能涉及各種形式的感知，例如電腦視覺、自然語言處理或感應器資料分析
- 推理能力
  - 能運用邏輯、因果和可用資訊，得出結論、進行推論及解決問題
- 計畫能力
  - 制定策略性計畫來達成目標，根據可用資訊和期望的結果，找出必要步驟、評估可能的行動，並選擇最佳行動方案
  - 可能涉及預測未來狀態和考量可能遇到的障礙。
- 行動能力
  - 具備根據決策、計畫或外部輸入內容，採取行動或執行工作的能力
- 調用並使用工具的能力
  - 能調用外部工具或 API（檔案操作、搜索、計算等），且理解工具的是用情景與限制
- 記憶與上下文管理能力
  - 能保留和回憶過往訊息，並能正確檢所、篩選與整合相關記憶
  - 涉及短期記憶、長期記憶、系統記憶
- 溝通能力
  - 有理解和尊重使用者觀點的能力，且能用自然語言互動，且能提供清晰的解釋與推理過程，或表達不確定性與需要澄清之處
- 自我修正能力
  - 可從經驗中學習、根據意見回饋調整行為，並隨著時間的累積，持續提升效能和功能

# ai agent skill

- 針對某一類特定工作，替ai agent預先設計的工作流、檢查清單、或最佳實踐指南

## skill的特徵

| 特徵        | 說明              |
| --------- | --------------- |
| **目標專一**  | 針對特定任務設計，不是通用工具 |
| **預先設計**  | 工作流、步驟、檢查清單都已定義 |
| **可重複使用** | 同一個 Skill 可用多次  |
| **包含規則**  | 內部有協作邊界、決策點、檢查項 |
| **可組合**   | 多個 Skill 可以串聯   |
| **結構化**   | 有明確的流程和檢查清單     |

## skill的優點

| 優點 | 說明 | 對誰有利 |
|------|------|---------|
| **降低認知負荷** | 不用每次都重新想「怎麼做」 | 👤 使用者 |
| **提高效率** | 流程標準化，避免重複思考、溝通 | 👤 使用者 + 🤖 Claudian |
| **確保品質** | 有檢查清單，不容易漏步驟 | 👤 使用者 |
| **經驗累積** | 結果可記錄，持續改進 | 👤 使用者 |
| **減少誤解** | 協作邊界清楚，不用每次都協商 | 👤 使用者 + 🤖 Claudian |
| **快速啟動** | 一句話就能啟動完整工作流 | 👤 使用者 |
| **一致性** | 多次執行結果風格統一 | 👤 使用者 + 👥 知識庫 |
