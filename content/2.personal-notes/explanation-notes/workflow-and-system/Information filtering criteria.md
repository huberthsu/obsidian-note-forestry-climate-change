# 說明

- 打造第二大腦
  - [[Inspiration]]
    - 引發想像力、想法、靈感
  - [[Use]]
    - 未來派得上用場的內容、圖片、數據
  - [[Related]]
    - 與自身的關聯性
  - [[Surprise]]
    - 顛覆原本想法
    - 與原有觀點衝突
- 學習如何學習
  - 內容價值評分表
    - 是否有科學根據
    - 是否有嚴密論證
    - 是否能幫助自己突破認知、獲得新觀點
    - 是否給出明確的方法
    - 是否有完善的知識體系
    - 網站與網路評價是否較高
    - 是否為一手資訊
    - 分享的經驗是否來自真實實踐
  - 依據價值濃度，判斷可以做成幾張卡片筆記
